# Cotizador de Pintura

Sistema web para cotizar mano de obra de pintura (Bonao, RD). Funciona desde el iPhone con conexión o sin ella (offline).

## Funciones
- Medición de paredes por área: ancho × alto en **metros, pies o centímetros** (conversión automática a m²).
- Descuento automático de **puertas, ventanas y otras aberturas**.
- **Techos** opcionales con precio propio.
- **Precios editables** de mano de obra (RD$/m²) y cargos adicionales.
- Resumen con áreas brutas/netas y total en RD$.
- Guardar/recuperar cotización en el dispositivo + **Imprimir / Guardar PDF**.
- **Acceso con PIN**: crea tu código la primera vez que entra (solo tú).

## Publicado
- GitHub Pages: https://samuel-07.github.io/cotizador-pintura/

## Uso offline en iPhone
Abre el enlace en Safari → botón Compartir → **"Añadir a pantalla de inicio"**. La app queda como ícono y funciona aunque no haya internet.

> Nota: el PIN es una protección de cortesía en el navegador (los datos viven en tu propio dispositivo). No sustituye una autenticación de servidor, lo cual es suficiente para uso personal.
